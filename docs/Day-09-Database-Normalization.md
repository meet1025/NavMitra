# Day 09 — Database Normalization

## Objective

To normalize the NavMitra database and reduce data
redundancy and possible data anomalies.

## Work Completed

1. Studied database normalization.
2. Studied insertion, update and deletion anomalies.
3. Applied First Normal Form (1NF).
4. Applied Second Normal Form (2NF).
5. Applied Third Normal Form (3NF).
6. Separated common and role-specific user information.
7. Separated Product and Listing information.
8. Separated Order and Order_Item information.

## Normal Forms

- 1NF — Atomic values and no repeating groups.
- 2NF — No partial dependency.
- 3NF — No unnecessary transitive dependency.

## Outcome

The NavMitra database structure was reviewed and
organized according to normalization principles to
reduce redundancy and improve data consistency.
