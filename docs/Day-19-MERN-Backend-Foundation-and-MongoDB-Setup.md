# Day 19 – MERN Backend Foundation & MongoDB Setup

**Project:** NavMitra  
**Subtitle:** A Smart Demand-Driven Farmer-to-Buyer Agricultural Platform  
**Day:** 19  
**Topic:** MERN Backend Foundation & MongoDB Setup

---

## 1. Objective

The main objective of Day 19 was to start the actual backend development of the NavMitra project using the MERN stack.

The backend structure was prepared using Node.js and Express.js, and Mongoose was added for MongoDB database integration.

The project was also organized into separate folders so that future backend development can be done in a proper structure.

---

## 2. Final Technology Stack

NavMitra is being developed using the MERN stack.

MERN stands for:

- **M** → MongoDB
- **E** → Express.js
- **R** → React.js
- **N** → Node.js

The planned application architecture is:

```text
Frontend
   ↓
React.js
   ↓
Express.js
   ↓
Node.js
   ↓
Mongoose
   ↓
MongoDB
