# Day 07 — Database Design

## Objective

To design the database structure for the NavMitra
demand-driven farmer-to-buyer agricultural platform.

## Work Completed

1. Identified major database entities.
2. Designed tables for users, farmers and buyers.
3. Designed product and listing structure.
4. Designed order and order-item structure.
5. Designed payment and review structure.
6. Identified primary keys and foreign keys.
7. Defined relationships between tables.
8. Ensured consistency with the Class Diagram and Data Dictionary.

## Main Tables

- USER
- FARMER
- BUYER
- PRODUCT
- LISTING
- ORDER
- ORDER_ITEM
- PAYMENT
- REVIEW

## Outcome

The initial relational database design for NavMitra
was completed and aligned with the project's requirements.
