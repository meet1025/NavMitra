# Day 04 — Data Flow Diagram

## Objective

The objective of Day 04 was to understand and design the Data Flow Diagram (DFD) for NavMitra.

## Work Completed

- Understood the concept of Data Flow Diagram.
- Identified the external entities of NavMitra.
- Identified major system processes.
- Identified major data stores.
- Created the Context Diagram (Level 0).
- Created the Level 1 DFD.
- Connected the DFD with the SRS requirements.

## External Entities

1. Farmer
2. Buyer
3. Admin

## Major Processes

1. User Management
2. Product Management
3. Demand Management
4. Matching
5. Deal & Order Management
6. Notification Management
7. Admin & Reporting

## Major Data Stores

- User Data
- Product Data
- Demand Data
- Match Data
- Deal / Order Data
- Notification Data

## Main Data Flow

The main data flow of NavMitra starts with farmer product information and buyer demand information.

The system processes this information through the matching module using product, quantity, price, location and availability.

Suitable matches can then lead to interest, deal creation, order processing and transaction completion.

## Result

The DFD provides a clear view of how information moves through the NavMitra system and how the different modules interact with the stored data.
