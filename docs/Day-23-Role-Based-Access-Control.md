# Day 23 – Role-Based Access Control

## 1. Day Objective

The objective of Day 23 was to implement Role-Based Access Control (RBAC) in the NavMitra backend.

JWT authentication verifies whether a user is logged in. Role-based authorization controls which APIs a particular type of user is allowed to access.
