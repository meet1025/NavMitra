# Day 11 — SQL Queries and Database Testing

## Objective

To test the NavMitra database using SQL queries and verify that the tables and relationships work correctly.

## Work Completed

1. Verified the NavMitra database and tables.
2. Inserted sample farmer and buyer records.
3. Inserted agricultural products.
4. Created farmer product listings.
5. Created sample orders.
6. Added order items.
7. Recorded sample payment information.
8. Added sample reviews.
9. Tested SELECT queries.
10. Tested JOIN queries.
11. Tested UPDATE operations.
12. Tested DELETE operations.
13. Verified Foreign Key relationships.

## SQL Operations Tested

* INSERT
* SELECT
* UPDATE
* DELETE
* JOIN

## Business Flow Tested

Farmer → Product → Listing → Buyer → Order → Order Item → Payment → Review

## Outcome

The NavMitra database was tested using sample data and SQL queries. The major tables, relationships and database operations were verified successfully.

## Implementation Note

The SQL queries and database testing performed during this phase were
used to validate the relational data requirements, relationships and
basic CRUD operations.

This testing was part of the database learning and validation phase.

The final NavMitra application will use MongoDB as the database,
implemented through the MERN stack.
